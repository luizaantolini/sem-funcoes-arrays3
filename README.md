# Atividade: Sem funções de arrays

### Descrição:
Desenvolvimento de três pequenos programas em JavaScript sem utilizar métodos prontos de arrays

### Requisitos:
- Não usar métodos nativos de manipulação de arrays; operações em vetores devem ser feitas manualmente.
- Código em JavaScript executável no navegador (cada exercício pode ter um `index.html` simples que carrega o `script.js`).

### Exercícios

1) 👽 Idades (4 pessoas)
- Leia a idade de 4 pessoas e armazene em um vetor.
- Ao final, mostre qual foi a maior idade digitada e em que posição (índice) ela foi digitada.


2) 👩🏻‍💻Funcionárias (5 funcionários)
- Leia `nome`, `sexo` e `salário` de 5 funcionários e armazene esses dados em três vetores paralelos.
- Ao final, liste apenas os dados das funcionárias do sexo feminino (`'F'` ou `'f'`) que ganham mais de R$ 5.000,00.


3) 🪼 Alturas (quantidade variável)
- Colete e armazene nomes e alturas de pessoas.
- Permita que o usuário insira quantas entradas desejar; o programa só encerra quando o usuário optar por parar.
- Ao final, exiba a maior altura, a menor altura e a quem pertencem, respectivamente.
